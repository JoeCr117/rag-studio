# Home

Welcome to RAG Studio Vault, a study guide to the ideas behind RAG Studio: how folders of files become vector databases, how a question finds the right passages, and how a local model writes an answer from them.

- **Who it is for:** a learner starting from zero. Nothing is assumed, and every term is defined where it first matters.
- **How each note reads:** a one-sentence definition first, then why it matters, how it works and where it appears in RAG Studio.
- **How to move around:** pick an area below. An area opens into groups and a group into notes, and notes link across to whatever they depend on.
- **The worked example:** RAG Studio itself. Hovering a dotted label in its interface shows the first paragraph of the matching note here.

## Reading it

The notes are written for [Obsidian](https://obsidian.md), a free note app. Outside Obsidian each note is readable, but the links between notes only work in Obsidian.

1. In Obsidian choose **Open folder as vault** and select the `RAGStudioVault` folder in RAG Studio.
2. Start from this note, or press `Ctrl+G` for the graph of how everything connects.
