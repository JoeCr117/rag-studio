# File header

Two lines naming the file and its source, added in front of every chunk before it is embedded, so a chunk from the middle of a file still says where it comes from.

- **Format:** File: and the path, then Source: and the source name.
- **Why:** a chunk such as a list of settings means little alone; the file name often carries the topic.
- **Also keyword-searched:** a question that names a file can match it.
- **In the Browse tab:** open Embedded text and vector on a chunk.
