# Features

The capabilities of RAG Studio, each written as what the user wants to do, how the app behaves when they do it, and the edge cases it must handle.

The app has one page with five tabs: Manage, Search, Ask, Browse and Models. A header and a slide-up terminal sit above and below every tab.

- [[Folder sources]] — registering folders to read from (Manage tab)
- [[Database management]] — creating, configuring, starting and deleting vector databases (Manage tab)
- [[Keeping databases current]] — connecting folders to databases and syncing changes into them (Manage tab)
- [[Finding passages]] — querying a database and seeing why each result ranked where it did (Search tab)
- [[Asking questions]] — answers written by a local model from retrieved passages, with citations (Ask tab)
- [[Browsing contents]] — looking inside a database: documents, chunks and vectors (Browse tab)
- [[Model library]] — every model the app can use, where it is stored, and freeing the space (Models tab)
- [[GPU memory guard]] — warning before a model start that would overfill the graphics card (everywhere)
- [[Activity log]] — the job list and live terminal that show what the app is doing (Manage tab and terminal)
- [[Learning popups]] — hover explanations that open notes in this vault (everywhere)
