# Learning popups

Labels in RAG Studio that name a concept have a dotted underline. Hovering one opens a short explanation taken from this vault, with a link that opens the full note in Obsidian.

## What the user can do

- **Hover a dotted label,** a status badge or a score to read what it means, in a sentence or two.
- **Follow the link** to the full note in Obsidian, the note-taking app this vault is written for.
- **Edit a note** and see the change on the next hover, with no restart.

## How it behaves

- **The popup text is the note's first paragraph,** shown as plain text: links become their words and formatting is dropped. This is why every note in the vault opens with a stand-alone definition.
- **Notes are found by name in any folder,** so notes can be reorganized without breaking the app, as long as names stay unique.
- **Some popups add a line about the current state,** for example why a button is disabled or what a status means for this database.
- **The vault is read-only to the app,** and only notes inside the vault can be read.
- **Automated checks** fail when the interface names a note that does not exist, or when the vault breaks its own rules ([[Vault Metadata]]).
